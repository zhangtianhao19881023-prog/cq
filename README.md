# 天昊助手

## 功能

- pymem 读取游戏内存
- “自动攻击”按钮：启动/停止游戏内置自动攻击
- 卡位处理（两步）：距目标 > 2 格、且这个距离连续 5 秒没变化 → 第1次只换目标；再次选中它仍然卡住（距离还5秒未变）→ 拉入“卡位名单”不再选（打到掉血会重置）
  - 怪离开 16 格（掉出 ActorList）会自动移出名单
  - **不会因为“全部拉黑”就清空名单重来** —— 那样会让名单反复失效，几个卡住的怪会在里面进进出出。全拉黑时视为“没怪”，自动寻路继续走，把人带走
- “路线设置”页：自定义坐标列表，点“开始寻路”后依次循环走完；与自动攻击联动 —— **有怪时真正停止寻路**（不是只停发新指令，会再下发一次 `SetTarget(当前坐标)` 把已经开始的走路打断），怪清空后自动继续（索引不重置）。**判断依据是“能打的怪”数量** —— 和“怪物数量：N”标签共用同一个列表（`_monster_list_for_ui`），再额外**排除卡位名单**（`_attackable_monsters`）：显示 0 只、或者剩下的全在卡位名单里，都会继续走；有真正能打的怪才停下
  - 实现方式：调用游戏内部 `SetTarget(X,Y)`（`icqs5rhqqp.exe+0x1D32AC`），让客户端自己寻路，**不是鼠标点击**
  - 到达判定放宽 1 格（目标格常被怪/人占住，游戏会在旁边停下）
  - 停下但没到 → 2.5 秒后重发指令；重发 6 次仍不动 → 跳过该点
  - 加坐标 4 种方式：① 手动填 X/Y ②「取坐标」③「录制路线」——点开始录制后，在游戏里点小地图选点，每点一次自动记一个，不用手填 ④「批量粘贴」——一行一个坐标（支持 `313,187` / `313 187` / `313-187`）
  - 页面布局：第一排 `录制路线` `批量粘贴` + X/Y + `添加`；第二排 `删除` `清空` `取坐标` + 状态；下面是坐标列表；**最底部**是方案存取
  - **方案存取**：`保存` + 方案名 → 把当前坐标列表存成具名方案；`已存方案` 下拉框选名字 → `读取` 直接换回那套坐标；`删除方案` 把名字和坐标一起删掉。所有方案存在 config.json 里，下次开辅助还在
  - `保存` **只存设置**：自动攻击 / 开始寻路 的开关状态、以及寻路走到第几个点，都**不会**被保存；每次启动都从第一个点重新开始
- 显示怪物数量
- 显示怪物列表：名称、X/Y 坐标、当前血量/最大血量、到玩家的距离
  - **距离过滤**：曼哈顿距离 > 16 格的怪直接从源头丢弃（`MONSTER_MAX_DIST`）。客户端会把已经走远的怪继续留在 ActorList 里，这种“残影”超出攻击距离，选中它只会白白触发卡位判定并拉黑
- “拾取列表”页：左边是地上物品列表（名称 / X / Y / 距离 / 对象地址），右边是**可编辑的过滤关键词表**（一行一个），带 **自动捡物**
  - `自动捡物` 开关 + 范围（默认 8 格）在**「挂机技能」页最底部那一排**（自动捡物 → 范围 → 自动攻击 → 开始寻路，保存贴最右）；↑ 打开后 **走到物品所在格子，客户端会自己把东西捡起来**
  - 实现只用寻路那个 `SetTarget` 调用（已验证稳定），**不发鼠标点击、不按拾取键**
  - 站到格子上 2 秒（`PICK_WAIT_SEC`）物品还在 → 判定捡不起来，跳过该物品 20 秒（`PICK_FAIL_COOLDOWN`）后允许重试
  - **打死怪后会自动停下来捡东西**：最多暂停打怪 8 秒（`LOOT_PAUSE_SEC`）专门捡，捡完立刻继续打；否则人物会马上扑向下一只，爆的东西还在原地就已经走远了
  - 自动攻击有当前目标时不抢移动权（状态显示“打怪中，暂不捡”），免得和自动攻击互相拉扯
  - 走不到的物品：一直没靠近（8 秒 `PICK_REACH_SEC`）→ 判定到不了，跳过 20 秒
  - **名称过滤**：`不过滤` / `只捡` / `不捡` 三种模式，关键词写在**右边的文本框里，一行一个**（部分是配）。例：选“只捡”、右边写两行 `药` 和 `装备`，就只捡名字里带“药”或“装备”的。
    改完**点一下别处就自动保存**（`config.json` 的 `pickup.fkeys`），关窗口时也会存一次；不想等自动存也可以按“挂机技能”页的 `保存`
  - 跳过的物品在列表里会**标灰并显示 `(跳过)`**（捡不起来，或被名称过滤挡掉）
- “背包”页：40 格背包物品列表，顶部显示占用数（如 25/40）
- “挂机技能”页整合人物信息和全部自动技能功能，每个功能一行：
  - 人物信息：角色血量、人物 X/Y 坐标
  - 治愈术：低血自动放技能，默认 F1
  - 背包负重超限处理
  - 隐身术：程序启动后自动运行，读取人物状态位 +0xA8 & 0x100；未隐身且周围怪物达到阈值时按隐身键（默认 F2），已隐身时不重复按键
  - 宠物召唤：程序启动后自动运行，每次读取当前角色名并匹配宠物名称中的主人；宠物对象不存在时按 F8，存在时不按键，支持切换角色
    - 防误判（按实测行为设计，避免"宝宝只是跑远了"被当成没了）：
      1. **走动着读不到** → 不判定（寻路/跑动时宝宝被拉开距离、掉出客户端"附近对象"列表）
      2. **站住且连续 ≥10 秒**读不到（`PET_GONE_SEC`）→ 按一次召唤键（状态栏显示"站住确认中 x/10s"）
      3. 按完 **3 秒内**（`PET_SUMMON_VERIFY_SEC`）看身边有没有冒出宝宝：
         - 冒出来了 → 之前确实没了，召唤成功
         - 一直没冒出来 → **宝宝其实还在**（只是距离远），不再按，避免浪费召唤
         - 一旦认定"还在"就**不再按了**（召唤消耗护身符和蓝），直到真的再读到宝宝才恢复判定
- 只过滤怪物，不显示玩家和 NPC

## 使用

1. 先启动游戏，并进入游戏地图。
2. 双击 `启动辅助.bat`，或使用 PyCharm 打开本目录并运行 `main.py`。
3. 点击“自动攻击”开始攻击，再次点击停止。
4. 在“挂机技能”页查看人物信息，并设置低血技能、负重处理、周围技能和宠物召唤。
5. **页签顺序**：挂机技能 / 路线设置 / 怪物列表 / 拾取列表 / 背包。
   最底部一行：`自动捡物` + 范围[格] → `自动攻击` `开始寻路` → 状态 → **最右边贴边是 `保存`**。
6. **窗口可以自己拖大小**：启动时自动贴合内容（约 555x489，不多不少）；拉大时四个列表会自动变长，最小可以缩到 420x320。

如果程序提示“没有找到游戏进程”，会弹出进程选择窗口：

- 在列表里选择 `Icqs5rHQqp.exe`，双击或点击“连接”。
- 也可以在下面直接输入游戏 PID。
- 如果提示无法打开进程，请用管理员身份运行 PyCharm 或 `启动辅助.bat`。

## 换电脑 / 迁移

**能用的前提是"同一个游戏客户端"。** 所有内存偏移都是 `icqs5rhqqp.exe + 固定偏移`
（进程名也写死成 `icqs5rhqqp.exe`），所以：

- 同一份客户端文件（同版本）→ 直接能用
- 换了别的服、或者客户端更新过 → 偏移全部失效，需要重新定位

**可以放心拷的：**

| 文件 | 说明 |
|---|---|
| `main.py` | 没有任何写死的绝对路径 |
| `启动辅助.bat` | 用 `%~dp0` 定位本目录，换盘换路径都行 |
| `config.json` | 全部设置都在里面（按键/阈值/坐标/方案/过滤词），拷过去接着用 |
| `README.md` | — |

**不要拷 `.venv`**：里面 `pyvenv.cfg` 记着本机 Python 路径（本机是 `D:\python`），
换台电脑路径不一样就用不了。新电脑重新建一个即可，反正只有 11MB、一条依赖。

**新电脑步骤：**

```bat
:: 1. 装 Python 3 (64 位) 后，在本目录执行：
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

:: 2. 右键 启动辅助.bat -> 以管理员身份运行
```

注意：辅助**必须以管理员身份运行**，否则打不开游戏进程（会提示"无法打开游戏进程"）。
另外部分杀毒软件会把内存读写类程序拦下来，必要时把本目录加进白名单。

## 多客户端配置

跟客户端绑定的所有数值都抽到 **`clients.json`** 了，换客户端**不用改 `main.py`**。

```json
{
  "profiles": {
    "icqs5rhqqp": {
      "备注": "当前客户端",
      "PROCESS_NAME": "icqs5rhqqp.exe",
      "MODULE_NAME": "icqs5rhqqp.exe",
      "OFF_PLAYER": "0x2FA918",
      "OFF_MOVE_FUNC": "0x1D32AC",
      "MONSTER_VMTS": ["0x005B74E8", "..."],
      "...": "其余 40 多项"
    },
    "另一个服": {
      "PROCESS_NAME": "mir2.exe",
      "MODULE_NAME": "mir2.exe",
      "OFF_PLAYER": "0x????????",
      "...": "..."
    }
  }
}
```

**加一套新客户端**：把整个 `icqs5rhqqp` 那块复制一份，改名 + 换成新客户端测出来的值即可。

**选哪一套**（按顺序）：

1. `config.json` 里 `client` 字段记着的那个
2. 当前**正在运行**的游戏进程名，能和哪套的 `PROCESS_NAME` 对上就用哪套
3. 都没有就用第一套

也可以在**顶栏「客户端」下拉框**里手动切 —— 切换会立即用新偏移重新绑定，
并把选择写进 `config.json`，下次启动自动用那套。

其它细节：

- 数值写 `"0x2FA918"` 十六进制字符串、或普通十进制数字都行
- `MONSTER_VMTS` / `NPC_KEYWORDS` 写数组，程序会自动转回 set / tuple
- `clients.json` 缺失或写坏 → 自动退回 `main.py` 里的默认值，不会崩
- **不需要按客户端配的量**（重发间隔、宝宝判定秒数、窗口宽度…）仍在 `main.py` 第 59~67 行

## 注意

- **不要和 Cheat Engine 同时开。** 这个客户端会检测 CE：开着 CE 时辅助连上去约 25 秒就会掉线；单独开辅助（CE 完全退出）实测长时间不掉线。用 CE 时请先把辅助关掉，用完 CE 记得**结束进程**（不是只分离调试器）。
- 游戏更新后偏移可能变化，需要重新定位。
- 程序关闭时会自动停止自动攻击和自动技能。
- 该程序只读取内存和切换游戏内置自动攻击开关，请仅用于你有权分析的环境。
